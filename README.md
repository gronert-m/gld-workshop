# Global Labor Database Workshop

The Global Labor Database (GLD) harmonizes labor-market survey microdata into a common data dictionary and makes the underlying code and documentation available for inspection, reproduction, and reuse. This workshop uses the Pakistan Labour Force Survey 2024-25 to show how researchers can work with the standard harmonization and build on it for their own questions, without reconstructing the entire survey. The emphasis is on transparent coding decisions, respect for the source survey, and a traceable path from questionnaire information to analysis.

The workshop follows four blocks: **Understand and Navigate the GLD** introduces its documentation and traces the construction of selected variables; **Reproduce a GLD Harmonization** obtains the original inputs, resolves file dependencies, and checks the output; **Expanding the GLD** adds an alternative ICLS-13 employment definition and workplace and commuting variables while preserving the standard variables; and **From Harmonization to Analysis** examines commuting patterns with and without occupation controls, then links external occupational AI exposure and complementarity scores to compare education and sex groups. Together, the blocks demonstrate how harmonization supports both survey-specific research and interoperability with other data sources.

The main workflow uses Stata, with R and Python versions available for the reproduction exercise. Execution is encouraged but optional during the session: participants can follow the code walkthrough and interpret the reported checks and results without installing software. Survey microdata must be obtained directly from the Pakistan Bureau of Statistics; this repository does not distribute them. The handouts provide the input links, software requirements, code, and checks needed to work through the exercises.
